# Sq2Cube - AI Backend (Single Object 3D Reconstruction)

This module contains the AI/ML pipeline for Sq2Cube.

## Pipeline

1. Image Quality Validation
2. Preprocessing
3. Object Segmentation
4. COLMAP Pose Estimation
5. NeRF Training
6. Mesh Extraction
7. Confidence Evaluation
8. 3D Asset Export

## Technologies Used

- COLMAP
- PyTorch
- OpenCV
- Open3D
- Segment Anything Model

## Execution Environment

All experiments are executed on Google Colab GPU.
